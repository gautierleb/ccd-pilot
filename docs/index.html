textkit

Small text helpers, standard library only. Every public function is listed below with one example.

collapse_whitespace

collapse_whitespace(text: str) -> str

Returns the text with every run of whitespace as one space and none at either end; an empty text gives an empty string.

>>> collapse_whitespace("  hello   \n world  ")
'hello world'

initials

initials(name: str) -> str

Returns the upper-cased first character of each whitespace-separated word in the name; an empty or whitespace-only name gives an empty string.

>>> initials("ada king lovelace")
'AKL'

slugify

slugify(text: str) -> str

Returns the text lower-cased with every run of characters other than a-z and 0-9 as one "-", without leading or trailing "-"; an empty text gives an empty slug.

>>> slugify("Hello, World! 2024")
'hello-world-2024'

truncate

truncate(text: str, width: int, *, ellipsis: str = "…") -> str

Returns the text cut to at most width characters, ending in the ellipsis when it was cut; an empty text stays empty.

>>> truncate("The quick brown fox", 10)
'The quick…'
